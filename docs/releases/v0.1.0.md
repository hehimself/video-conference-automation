Keypad Studio is a visual profile editor and background companion for the Raspberry Pi Pico with the Pimoroni RGB Keypad Base.

## Downloads

| Computer | Download |
| --- | --- |
| Mac with Apple Silicon (M-series) | `Keypad-Studio-0.1.0-macOS-arm64.dmg` |
| Mac with an Intel processor | `Keypad-Studio-0.1.0-macOS-x86_64.dmg` |
| Windows, 64-bit Intel/AMD | `Keypad-Studio-0.1.0-Windows-x64.zip` |

On Mac, open the disk image and drag **Keypad Studio** into **Applications**. On Windows, extract the entire ZIP and open **Keypad Studio.exe** inside its folder. Keep the accompanying `_internal` folder. Python is not required to run the app. Your own Python scripts still need a configured interpreter.

These community builds are unsigned by a commercial publisher; the Mac app has an ad hoc signature and is not notarized. macOS Gatekeeper or Windows SmartScreen may show a warning. See [Apple's guidance](https://support.apple.com/guide/mac-help/open-a-mac-app-from-an-unknown-developer-mh40616/mac) if macOS blocks opening the app. Signing and notarization are not configured for this release.

## Included

- Visual 16-key editor with Current Pico and Classic Conference starter profiles, Mac/Windows bindings, sequences, scripts, and lighting presets.
- Save the active profile to the Pico; standalone shortcuts, media controls, macros, and lighting work after unplugging or quitting the app.
- Neutral light and dark-gray themes, blue accents, white primary-button text, and native application icons.
- Normal window close, Command-Q, Dock Quit, and tray Quit; explicit **Keep companion running** mode.
- CircuitPython 10.3.1 and HID 6.1.4 setup resources, with private backup and read-back verification.

The release workflow tests each OS/architecture, launches the packaged client with isolated settings and no hardware connection, checks shutdown and the packaged ZIP helper, and verifies firmware resources before publishing. `SHA256SUMS.txt` contains checksums for the three downloads.

Physical Pico mapping and German Mac HID output were checked on the connected device. Physical Windows HID behavior, per-application Windows audio controls, and live Teams/Discord meeting behavior still require hardware/application validation. Shortcut-based mute indicators track local key presses, not verified application state.
